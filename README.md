# AIAPPLIED

Public blog hosting is set up with GitHub Pages via workflow in `.github/workflows/deploy-pages.yml`.

## One-time GitHub settings

1. In GitHub, open **Settings → General → Change repository visibility** and set this repo to **Public**.
2. Open **Settings → Pages** and set **Source** to **GitHub Actions**.

After that, each push to `main` deploys automatically.
